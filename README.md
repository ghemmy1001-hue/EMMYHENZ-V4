# EMMYHENZ-V4 🤖

A modular WhatsApp bot built with Node.js and Baileys, featuring group management, security tools, AI, media commands, games, utilities, and phone-number pairing.

## ✨ Features

- Modular command system
- WhatsApp connection with Baileys
- Phone-number pairing
- Group administration
- Anti-link protection
- Anti-badword protection
- Anti-tag protection
- Anti-bot protection
- AFK system
- AI commands using OpenRouter
- Media and download commands
- Games and fun commands
- Welcome/goodbye system
- Pairing web interface
- Large collection of commands
